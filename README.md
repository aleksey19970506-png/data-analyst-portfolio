## Проекты

### 1. Яндекс Афиша: EDA и проверка продуктовых гипотез

📓 [`yandex-afisha-eda.ipynb`](yandex-afisha-eda.ipynb)

Анализ заказов билетного сервиса за 2024 год.

- **Предобработка:** типы данных, пропуски, неявные дубликаты, аномалии по 99-му перцентилю, конвертация тенге в рубли по курсу.
- **EDA:** динамика заказов по месяцам и дням, сезоны (лето/осень), регионы, типы событий, DAU, топ-мероприятия, билетные партнёры.
- **Статистика:** две гипотезы о различиях mobile и desktop проверены t-тестом Уэлча.
- **Результат:** 14 графиков, выводы по каждому разделу и рекомендации для продукта.

**Стек:** Python, pandas, NumPy, matplotlib, SciPy, Jupyter Notebook.

> Данные предоставлены Яндекс Практикумом и в репозиторий не включены: ноутбук сохранён с выполненными ячейками и графиками, чтобы код и результаты были видны без запуска.
